# Händler-Dashboard

Aus diesem Ordner mit `python -m http.server 8080 --bind 127.0.0.1` starten und im Browser `http://127.0.0.1:8080` öffnen. Das Dashboard zeigt lokale Beispieldaten. Die sechs Bereiche sind über URL-Fragmente direkt erreichbar.

`data.mjs` bündelt die Abfragen für die spätere Mitarbeiter-Anmeldung. Produktpreise beziehen sich in der Demo auf den Beispielkunden. Bestände sind je Artikel und Lager gruppiert.
